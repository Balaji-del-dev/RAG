1What is an LLM?

Interview answer — say this first
In simple words

An LLM is a computer program that has read a huge amount of text and has become very good at guessing the next word. It writes an answer by guessing one small piece of text at a time.

2Why do we need it?

Before LLMs, every language task needed its own special program: one for translation, one for summaries, one for answering questions. Each program needed its own training data and rules, and it could not understand normal, free-form questions.

An LLM learns language in general. So one model can do many tasks — answer questions, summarize, translate, write code, pull data out of documents — just by reading an instruction written in plain English. This instruction is called a prompt.

Without an LLM

  • A separate model for every task
  • Fixed rules and keywords
  • Cannot understand free-form questions

With an LLM

  • One model for many tasks
  • Understands normal language
  • Just write an instruction (a prompt)

3How does it work?

When you send a question, the LLM does these five steps. Steps 1–5 produce one token. Then the whole process repeats for the next token.

1

Split the text into tokens

The input text is cut into small pieces called tokens. A token is a word or a part of a word (lesson 02).

Example: "The capital of France is" → The ␣capital ␣of ␣France ␣is
2

Turn each token into numbers

A computer can only work with numbers. So each token becomes a list of numbers called an embedding, which represents its meaning (lesson 03).

Example: ␣France → [0.12, −0.48, 0.91, …] (thousands of numbers)
3

Understand the context

The numbers pass through many transformer layers. In each layer, every token looks at the other tokens to understand the meaning of the whole sentence. This is called attention (lesson 04).

Example: the model connects "capital" with "France", so it knows a city name should come next.
4

Calculate a probability for every possible next token

The model gives a score to every token it knows (its vocabulary, about 100,000 tokens) and turns the scores into probabilities that add up to 100%.

Example: ␣Paris 92% · ␣a 3% · ␣Lyon 1% · …
5

Pick one token, add it, and repeat

One token is chosen (lesson 05) and added to the end of the text. Then steps 1–5 run again to produce the next token. This stops when the model outputs a special end token or reaches the length limit.

Example: "The capital of France is Paris" → next round → "The capital of France is Paris." → end.

The generation loop

Your text"The capital of France is"
Tokenssmall pieces of text
Transformerunderstands the context
ProbabilitiesParis 92% · a 3% · …
Next token" Paris"
↺ add the new token to the text and run again — until the end token

Draw this on the whiteboard. The name of this loop is autoregressive generation: each new token depends on all the tokens before it.

How is an LLM trained?

A chat model like ChatGPT, Llama or Qwen is trained in three main stages:

1. Pre-trainingreads trillions of tokens from books, websites and code, and learns to predict the next token
2. Supervised fine-tuning (SFT)learns from many example questions with good answers, so it follows instructions
3. Preference tuning (RLHF / DPO)learns which of two answers people prefer, so it becomes helpful and safe

After stage 1 you have a base model. After stages 2 and 3 you have a chat (instruct) model.

Remember

Some newer models get one more stage: they practise maths and coding problems with reinforcement learning, and learn to "think" step by step before they answer. These are called reasoning models.

Remember

The model did not look up Paris anywhere. During training it saw "capital of France" followed by "Paris" so many times that "Paris" became the most probable next token. That is why an LLM can also be confidently wrong when it has not seen the right information.

5Important terms

Token

A small piece of text, usually a word or part of a word. The model reads and writes tokens.

"unbelievable" → "un" + "believ" + "able"
Parameters (weights)

The numbers inside the model that are learned during training. More parameters means more capacity.

"7B" = 7 billion parameters
Context window

The maximum number of tokens the model can see in one request, including its own answer.

e.g. 128,000 tokens ≈ a 300-page book
Prompt

The text you give the model: the instruction, the question and any documents.

"Summarize this email in 3 lines: …"
Pre-training

The first and biggest training stage, where the model learns to predict the next token on a huge amount of text.

Fine-tuning

Extra training on a smaller, focused dataset to change how the model behaves.

Inference

Using an already-trained model to produce an answer. This happens on every user request.

Knowledge cutoff

The date where the training data ends. The model knows nothing that happened after this date.

Hallucination

When the model writes something that sounds correct and confident but is false or not supported by any source.

Open-weight model

A model whose weights you can download and run on your own computer or server.

Llama, Qwen, Mistral, Gemma, gpt-oss

7Advantages and limitations

Advantages

  • Understands normal human language
  • One model can do many tasks
  • New features need only a prompt, not new training
  • Works in many languages
  • Good at explaining, summarizing and writing code

Limitations

  • Can hallucinate (confidently wrong)
  • Knows nothing after its knowledge cutoff
  • Has never seen your private company data
  • Cannot show the source of its answer
  • Needs GPUs; slower and costlier than a database lookup
Remember

Most limitations are about knowledge. RAG (lesson 08) fixes them by giving the model the right documents at the moment the question is asked.

Real example: an HR assistant

An employee asks: "How many leave days can I carry over to next year?" A plain LLM has never seen this company's leave policy, so it guesses a common number — and may be wrong. With RAG, the system first finds the right paragraph in the leave policy and gives it to the LLM. The LLM then answers: "You can carry over up to 5 days [Leave Policy, page 6]."

In our platform

  • The LLM runs on our own servers through LiteLLM → Ollama or vLLM, so no data leaves the company.
  • Facts always come from retrieved document chunks, never from the model's memory.
  • Every answer is checked before it is shown: it must be supported by the cited sources (lesson 18).

9How to explain it in an interview

Your 1-minute answer

DefinitionAn LLM, or Large Language Model, is a large neural network, usually based on the transformer architecture, trained on massive amounts of text to predict the next token.

How it worksThe input text is split into tokens, and each token is converted into an embedding. Transformer layers use attention to understand the context, and the model then calculates a probability for every possible next token. It picks one token, adds it to the text and repeats the process until the answer is complete.

ExampleFor the input "The capital of France is", the token "Paris" gets the highest probability, so the model writes "Paris".

LimitationBecause it predicts likely text instead of checking facts, it can hallucinate, and it does not know private or recent information. That is why, in production, we combine it with RAG and citations.

Don't say"The LLM looks up the answer in its training data."
Say instead"It predicts the most likely next tokens from patterns learned in training. It does not search anything."
Don't say"We will fine-tune the model on our documents so it knows them."
Say instead"For knowledge we use RAG. Fine-tuning is for changing behaviour, style or format."
Don't say"Bigger models don't hallucinate."
Say instead"All LLMs can hallucinate. We reduce it with grounding, citations and answer checks."
