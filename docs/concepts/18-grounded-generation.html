1What is grounded generation?

Interview answer — say this first
In simple words

Grounded generation means the LLM must answer only from the retrieved documents, put a source number after every fact, say "the documents don't contain this" when they don't, and have its answer checked before the user sees it. The goal is to stop hallucination: confident answers that no source supports.

2Why do we need it?

Even with perfect retrieval, the LLM can still add facts from its memory, mix two sources, or cite the wrong page. In business use — HR, legal, finance, healthcare — one wrong answer can cause real harm. Grounding makes every answer verifiable.

Ungrounded answer

  • "You can carry over 10 days." (old 2025 policy)
  • No sources — the user can't check it
  • Guesses when the documents don't say

Grounded answer

  • "You can carry over up to 5 days [1]."
  • [1] = Leave Policy v3, page 6 — clickable
  • Says "not found in the documents" when needed
Analogy: an exam answer with sources

A student gets 5 pages of notes. A good answer uses only those notes, writes "(page 6)" after every fact, and says "the notes don't cover this" when they don't. A teacher then checks each fact against the notes. Grounded generation is exactly this.

3How does it work?

1

Select the best chunks

Take the top reranked chunks, usually 3–8.

2

Build a clean context

Expand small chunks to their parent section if needed, remove duplicates, prefer the current document version, put the strongest evidence first, and fit the token budget while keeping space for the answer.

3

Check: is there enough evidence?

If the best reranker score is too low, don't call the LLM at all. Abstain, or ask a clarifying question.

4

Generate with strict rules

Number each source with title, section and page. Instruct the model to answer only from the sources, cite every fact, and mark the question "not answerable" when the sources don't contain the answer.

5

Validate before showing

Check the format, check that every citation exists, that every fact has a citation, and that each claim is supported by its cited text. If a check fails, repair once or abstain.

Real example: conflicting sources

The 2025 policy says 10 days; the 2026 policy says 5 days. The system filters to the current version. If both are valid for different groups, it states the difference with both citations, instead of silently picking one.

Remember — "lost in the middle"

Models use information at the start and end of a long context best, and miss things in the middle. So send fewer, better chunks, and put the strongest evidence first.

5Important terms

Grounding

Basing the answer only on the provided sources, not on the model's memory.

Hallucination

An answer that is false or not supported by any source.

Faithfulness

The share of claims in the answer that the context supports.

Citation

A link from a claim to its source chunk, document version and page.

Abstention

Saying the answer isn't in the documents, instead of guessing.

Context assembly

Choosing, cleaning and ordering the chunks that go into the prompt.

Lost in the middle

Models use information in the middle of long contexts less reliably.

NLI

Natural Language Inference: a model that checks whether a text supports a claim.

7Advantages and limitations

Advantages

  • Answers users can verify
  • Far fewer hallucinations
  • Honest "not found" instead of guesses
  • Audit trail: which source supported which claim

Limitations

  • Validation adds latency
  • Too strict a threshold → too many "not found"
  • Faithfulness checkers can also make mistakes
  • Only as good as the retrieved chunks

9How to explain it in an interview

Your 1-minute answer

DefinitionGrounded generation is making a language model answer only from the retrieved source passages, with every factual claim supported by and cited to those sources. Its purpose is to minimize hallucination.

HowI assemble a focused context from the top reranked chunks: expand to parents where needed, remove duplicates, put the strongest evidence first and fit the token budget. The prompt requires a citation for every fact and offers an explicit "not answerable" option.

ChecksBefore generation, a low reranker score triggers abstention. After generation, I validate the schema, the citation references and coverage, and check faithfulness with an NLI model or a small LLM judge; if it fails, the system repairs once or abstains.

Example"You can carry over up to five days [1], and they must be used by 31 March [2]", where each number links to a document version and page.

Don't say"Fill the context window with as many chunks as possible."
Say instead"Fewer, highly relevant chunks give better answers. Extra text adds noise and cost."
Don't say"If the LLM returns an answer, it is grounded."
Say instead"We validate citations and check that each claim is supported before returning the answer."
