How to use this path

1 · Go in order

Lessons depend on earlier ones. Lesson 04 (transformers) needs 02 and 03; lesson 16 (hybrid search) needs 12–14.

2 · Same shape every time

What you will learn → why it matters → core ideas → how it works → real-world practice → common mistakes → in our platform → check yourself → go deeper.

3 · Test yourself

Answer the "Check yourself" questions before opening the answers. If you can't, re-read that section.

4 · Mark it learned

Use the button at the bottom of each lesson. ← and → keys move between lessons.
