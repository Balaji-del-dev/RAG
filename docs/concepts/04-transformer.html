1What is a transformer?

Interview answer — say this first
In simple words

A transformer is the design used inside every modern LLM. Its key idea is attention: when it reads a word, it looks at all the other words in the sentence and decides which ones matter most for understanding that word.

2Why do we need it?

Before transformers, language models (RNNs and LSTMs) read text one word at a time, like reading through a tube. By the end of a long paragraph they had "forgotten" the beginning, and they were slow to train because each word had to wait for the previous one.

Older models (RNN / LSTM)

  • Read one word after another
  • Forget information over long distances
  • Slow to train — hard to use many GPUs

Transformer

  • Reads all tokens at the same time
  • Any token can connect directly to any other token
  • Fast to train on GPUs, so models could become huge
Analogy: how you understand "it"

"The animal didn't cross the street because it was too tired." To understand "it", your brain looks back and links it to "animal", not "street". Self-attention does exactly this, for every token, using numbers.

3How does it work?

1

Turn tokens into vectors and add their position

Each token ID becomes an embedding vector. Attention by itself does not know word order ("dog bites man" vs "man bites dog"), so position information is added. Modern LLMs use a method called RoPE.

2

Self-attention: every token looks at the other tokens

Each token decides how much every other token matters to it, gives each one a weight, and mixes in their information. After this step, the vector for "it" contains information about "animal".

Example: weights for "it" → animal 0.55 · street 0.18 · it 0.10 · others small (all add up to 1)
3

Feed-forward network: process each token

A small neural network then processes each token's vector on its own. This is where much of the model's learned knowledge is stored.

4

Repeat in many layers

Steps 2 and 3 form one transformer block (layer). The model stacks many of them; each layer builds a deeper understanding. An 8B model has about 32 layers; a 70B model about 80.

5

Predict the next token

The final vector goes into an output layer that gives a probability for every token in the vocabulary (lesson 01).

How attention calculates the weights: Query, Key, Value

Analogy: searching in a library

Query = what you are looking for ("a book about animals"). Key = the label on each book. Value = the content inside the book. You compare your query with every label; the better the match, the more of that book you read. In attention, every token does this with every other token.

  1. Make Q, K and V. Each token vector is multiplied by three learned matrices to get a query, a key and a value.
  2. Score. Compare each query with every key using a dot product: Q · Kᵀ.
  3. Scale. Divide by √d_k (the size of the key) so the scores don't become too large.
  4. Mask. In chat models, hide future tokens, so a token can only look at earlier tokens.
  5. Softmax. Turn the scores into weights that add up to 1.
  6. Mix. The new vector = the weighted sum of the value vectors.
Attention(Q, K, V) = softmax( Q · Kᵀ / √d_k  +  mask ) · V

4Example: step by step

Attention for the token "it" (tiny numbers, d_k = 2)
  1. Raw scores of "it" against [animal, street, tired] = [2.0, 0.5, 0.1].
  2. Divide by √2 ≈ 1.41 → [1.41, 0.35, 0.07].
  3. Softmax turns them into weights → [0.62, 0.22, 0.16].
  4. So the new vector for "it" takes 62% of its information from "animal". The model now "knows" what "it" refers to.

5Important terms

Self-attention

Each token gathers information from the other tokens, weighted by how relevant they are.

Query, Key, Value (Q, K, V)

Query = what a token looks for. Key = what a token offers for matching. Value = the information it passes on.

Multi-head attention

Attention runs many times in parallel ("heads"). Each head can learn a different relation, such as grammar or references.

Causal mask

Stops a token from looking at future tokens. Used in models that generate text.

Positional encoding / RoPE

Adds word-order information. RoPE does it by rotating the Q and K vectors.

Feed-forward network (FFN)

A small neural network applied to each token after attention.

Residual connection + layer norm

Each block adds its output to its input and normalizes it. This keeps training of very deep models stable.

KV cache

Stored keys and values of earlier tokens, reused while generating so the model is faster.

GQA (grouped-query attention)

Several query heads share one K/V head, so the KV cache is much smaller.

MoE (Mixture of Experts)

Many feed-forward "experts", but only a few run for each token: big capacity, less compute.

In a RAG system you use both kinds: an encoder for embeddings and reranking, and a decoder LLM to write the answer.

7Advantages and limitations

Advantages

  • Understands long-range connections in text
  • Trains in parallel, so it scales to billions of parameters
  • One design works for text, code, images and audio
  • Same building block for embedders, rerankers and LLMs

Limitations

  • Attention cost grows with n²: doubling the text ≈ 4× the attention work
  • The KV cache uses a lot of GPU memory for long chats
  • Needs a lot of data and compute to train
  • Has a fixed maximum context length

Real example: "Why is our 128K-context chatbot slow and out of GPU memory?"

The team sends whole documents (100,000 tokens) in every prompt. Attention compares every token with every other token, and the KV cache grows with every token and every user. So each request is slow and uses many GB. The fix: use RAG with reranking and send only the few best chunks.

In our platform

  • A decoder LLM (through Ollama or vLLM) writes the answers. Its context size and KV cache decide how many users fit on one GPU.
  • Encoder models: the embedding model and the cross-encoder reranker.
  • The context budget step keeps prompts small, so answers are faster and use less memory.

9How to explain it in an interview

Your 1-minute answer

DefinitionA transformer is a neural network architecture, introduced in 2017, that processes all tokens in parallel and uses self-attention to relate each token to every other token.

How it worksEach token is converted into query, key and value vectors. The query of one token is compared with the keys of all tokens, softmax turns the scores into weights, and the token's new representation is the weighted sum of the values. Each block also has a feed-forward network, and many blocks are stacked.

ExampleIn "The animal didn't cross the street because it was tired", attention gives "it" a high weight on "animal", so the model understands what "it" refers to.

Trade-offTransformers replaced RNNs because they train in parallel and handle long-range context, but attention cost grows quadratically with length, and the KV cache uses a lot of GPU memory.

Don't say"BERT is used to generate chat answers."
Say instead"BERT is an encoder for understanding, like embeddings and classification. Chat LLMs are decoder-only."
Don't say"The KV cache stores the model weights."
Say instead"It stores the keys and values of earlier tokens, so they are not recomputed during generation."
Don't say"Doubling the context doubles the attention cost."
Say instead"Attention is quadratic: doubling the length roughly quadruples the attention compute."
