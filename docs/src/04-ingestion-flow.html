Durable dispatch

  • job and outbox rows commit before any Celery publish
  • on_commit alone can lose a task if the process dies after COMMIT
  • the dispatcher re-sends anything not yet DISPATCHED

Idempotent retries

  • deterministic chunk IDs; upserts keyed by chunk ID
  • failed jobs keep error details and attempt counts
  • reconciliation repairs missing, duplicate or orphaned index records

Never trust the browser

  • extension allow-list + MIME sniffed from content
  • size limits and content checks before storage
  • object keys generated server-side
  • uploader's permission and access groups checked on the server

First-release formats

  • PDF · DOCX · XLSX · PPTX · TXT · Markdown · CSV · JSON · XML · HTML
  • later, once text/table quality is measurable: image understanding, handwriting OCR, diagrams, visual embeddings
