Release gate without CI/CD

  • evaluation runs are application workflows on Celery
  • approval is a manual, audited step in React by the Release approver role — the approver is never the author
  • nothing publishes without a passing run on the current dataset version

Trustworthy LLM judging

  • DeepEval's judge runs locally through Ollama — no external API
  • small judges are noisier: calibrate against human-labelled cases
  • keep the judge model and version fixed across compared runs

Reproducible comparisons

  • runs pin dataset version, pipeline version and index generation
  • expected sources survive re-chunking (document + page / section)
  • per-case results make regressions visible, not just averages

Advanced retrieval is earned

  • query rewriting, multi-query, HyDE, decomposition, corrective retrieval and agentic routing
  • each enabled only when this loop shows a measurable gain
