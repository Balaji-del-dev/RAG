Grounding is checked, not assumed

  • abstain when evidence is thin
  • schema, citation and grounding checks before any answer is returned
  • one repair attempt, then abstain

One generation per query

  • physical index names come from PostgreSQL
  • Qdrant and OpenSearch are never mixed across generations
  • the generation ID is stored on the run for reproducibility

Measurable baseline first

  • dense + BM25 → RRF → cross-encoder is the starting point
  • query rewriting, multi-query, HyDE, decomposition, corrective retrieval and agentic routing only when evaluation shows a gain

Permissions in the query

  • access groups come from the session, never from the request
  • the same mandatory filter in Qdrant and OpenSearch
  • the LLM never sees text the user may not read

Trace privacy

  • spans carry IDs, timings and token counts by default
  • prompts and document text only where policy allows
  • trace_id joins Langfuse to retrieval_runs
